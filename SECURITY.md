# Reporting a security vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/TemMax/toki/security/advisories/new) to report a vulnerability. Do not put exploit details, credentials, account identifiers, private transcript content, or personal logs in a public issue or pull request.

Include the affected Toki version, a description of the impact, and steps to reproduce. Use test data and redact sensitive values. We will discuss the report privately before publishing any fix or advisory.
