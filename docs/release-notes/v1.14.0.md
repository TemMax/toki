## ✨ What's New

- New Speed tab: see how fast each model generates, in tokens per second, for Claude Code and Codex — by model, effort and Fast mode.
- A daily chart shows whether a model has become faster or slower over time. Select up to four rows to compare them.
- Choose which models the Speed table shows. Your choice is remembered.
- Speed history starts with the transcripts still on your Mac and is kept from then on, even after Claude Code cleans them up.

## 🛠️ Improvements

- The time-range picker on the Usage tab now sits on its own row under the tabs.
- Every tab has less empty space under the toolbar.
- When Claude usage can't be refreshed, the note now appears in the Claude limits header instead of taking a line of its own.
